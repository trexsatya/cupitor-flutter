Run as a local server — this harness fetches assets/js/utils.js and assets/js/sentence_tag.js and won't work from file:// in most browsers. From the Cupitor directory, run: python3 -m http.server 8765 then open http://localhost:8765/tools/real_page_harness.html.

Real-page harness

1. Visit the page you want to test in another tab. 2. Open DevTools → Elements → right-click on the root <html> → Copy → Copy outerHTML. 3. Paste below and click Load.

Or paste a URL on a line by itself and we'll try to fetch() it (works only when CORS allows, which most prose sites don't).
